# Microdatos requeridos

Para ejecutar `R/analysis.R` desde cero, ubica aquí:

- `BD.csv` — delitos en Colombia, 569.127 registros y 20 variables en el informe original.
- `Cadena_Productiva 3.xlsx` — producción, área sembrada y área cosechada por municipio.
- `Cultivos Ilicitos 2015-2019 3.xlsx` — área de cultivos ilícitos por municipio.

Estos archivos no fueron suministrados en el paquete recibido y pueden estar sujetos a condiciones de redistribución. El dashboard publicado utiliza exclusivamente las tablas derivadas que sí están incluidas en `data/derived/`.
